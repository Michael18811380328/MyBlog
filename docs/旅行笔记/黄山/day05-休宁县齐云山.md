# 第5天，齐云山

齐云山，位于安徽省黄山市休宁县齐云山风景名胜区，是典型的单鞋地貌，我进行了旅行和踏勘。

因为前一天晚上看到今天天气还可以，整体不下雨，气温也在30°以下，估计体感温度在30°左右，可以接受，所以我打算今天上午去齐云山，下午可能去西溪南等其他景点，根据时间安排。所以昨天晚上已经提前买好了车票。

早上大概6点半起床，7点钟去吃了一碗早饭，还是之前的笋丁浇头面，味道还可以。大约8点左右，坐上了去齐云山的长途大巴，差不多9点左右到达了齐云山风景区的大门口。

上齐云山有好几条路线，官方推荐搭乘往返缆车，票价110。官方还提供了去景区大门口的往返接驳大巴，价钱60多。这两种方式省去了开始这一阶段的大爬升，但价钱都比较贵。现在好多景区大门口都修得特别远，游客中心距离景区正式大门很远，门票不是特别贵，但往返交通支出不少。

但是我选择从游客中心直接徒步到景区大门口，这段实际是全程爬升最多的。游客中心海拔大约150米，到景区检票口海拔大约450米，其中一段爬升有13个亭子，将近1.5公里爬升300米，也就是每公里爬升200米，都是比较陡峭的连续长台阶，走得整个人都发热了，这段强度确实比较大。因为担心后续行程看景点需要更多时间，所以这段我也在高强度地走，已经把1/2的水喝完了。

这一段景色也是非常不错的。刚开始走出游客中心，中间是江水，江对岸是郁郁葱葱的森林。这时候还看不到任何岩层，因为森林覆盖非常密集。通过了明朝的登封桥，确实是几百年历史的古迹，非常棒的古桥。经过13个牌楼，不同海拔位置的周边环境发生了很大变化。150米海拔附近，周边还是农居，种了茶树和庄稼，因为受火山白垩纪沉积地层的影响，土壤偏红色，还保留着生活状态。慢慢走到半山腰，两旁的植被从小灌木变成了高大的松树之类的。

差不多走到海拔400米左右的时候，道路两侧就可以看到好多风化的白垩纪沉积岩，由于不同岩层的钙质交接物不一样，风化强度不同，形成了丹霞地貌。当然，这里的丹霞地貌并不是很典型。我只是做了简单记录，可以看出粗砂岩或砾岩等沉积岩之间有一些夹层和韵律特征，但这些观察不是很细致，相对于后面的来说。

大约10:35到达望仙楼，这里有"江南第一名山"的题词，实际上这里就是景区的验票口，从这里正式进入景区内部。景区内部这段路程基本上都是平整路段或起伏很小的路段，没有刚开始连续11座亭子那段的明显爬升。这段路走起来很舒服，毕竟是为了大部分游人方便。期间看了很多景点，这里就不一一赘述了，有好多是道教景点，也可以在山上俯瞰山下的整个环境——群山环抱中的皖南小村庄，旁边还有金色的稻田，特别美丽。

在一线天景点，这里有出露较好的地层，我进行了简单勘测，主要岩性可能是含砂砾岩，其中砾石磨圆性、分选性都比较差，砾石粒径在0.5mm到5cm左右，磨圆性差，多为尖锐棱角，判断当时水动力条件较强，可能是断陷盆地的冲积扇或泥石流沉积物所形成的。

过了一线天之后，在一些剖面上看到了沉积韵律特征，这些韵律特征是粗砂岩和砾岩的互层。我测试的这个剖面，每一层粗砂岩和砾岩厚度大约5cm，应该反映了不同季节流水动力的特征。先期可能有一次较大的洪水，造成砾岩沉积；后期水动力逐渐变弱，形成了较稳定的砂岩沉积。

这里还有一处特殊的生物遗迹，在小湖天顶景点附近的一层岩壁上，有动物遗迹的化石，其中可以清楚地观测到恐龙脚印。资料介绍有若干只成年恐龙和小恐龙。我实际测试的恐龙脚印长约30公分、宽约20公分，是三趾型的足迹；也有长15公分、宽10公分左右的，可能是不同体型、不同年龄的恐龙留下的。

接下来到最高峰附近，有一个高约近百米的岩层，有多个清晰的不同岩石类型的沉积韵律水平分布。经过测试，这里的沉积序列大致是细砂岩或泥岩→粗砂岩→砾岩，每一层厚度从10公分到20公分不等。不同泥岩颜色也有所不同，有的偏深棕色，有的偏红色，可能反映了当时不同的氧化还原环境。这里的砾石我也做了测量，分选性和磨圆性都比较差，说明当时水动力条件较强，其中某些砾石粒径在10公分以上，成分也非常复杂，可能有石英岩或其他沉积岩。因为现场没带工具，所以没有进行详细勘测。当然也有极少量的层级韵律，除了红色之外还有灰绿色的，推测是当时缺氧的还原环境所形成的。

在后面的一线天位置，形成了一个因外力风化侵蚀产生的极大的岩层空洞，空洞高度约两米，宽度15到20米左右，很多人可以进去纳凉。这应该是在沉积地层向上抬升的过程中，由于风蚀和流水侵蚀，薄弱地层被侵蚀得比较多，形成了著名的丹霞长廊。官方的解释是：由于岩层的硬度、厚度、成分和碎屑粗细不同，流水对含钙质的砂岩及砂岩胶结物的侵蚀和溶蚀速度快，形成崖洞；而钙质含量较少的纯净砂岩溶蚀作用没那么强，所以形成了下面是洞穴、上面是完整岩层的结构。这个特殊的丹霞地质现象我是第一次见，在其他地方还没有见过这么典型的。
