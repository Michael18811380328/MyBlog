## 408-linkify-it-py

This is Python port of [linkify-it](https://github.com/markdown-it/linkify-it).

[https://pypi.org/project/linkify-it-py/](https://pypi.org/project/linkify-it-py/ "https://pypi.org/project/linkify-it-py/")

用于将文本中的 URL 转换为可点击的链接。

> Links recognition library with FULL unicode support. Focused on high quality link patterns detection in plain text.
