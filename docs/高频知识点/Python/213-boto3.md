## 213-boto3

* **分类**：AWS 云服务 SDK

* **功能**：与 Amazon Web Services（AWS）交互，操作 S3、EC2、DynamoDB 等服务。

* **PyPI**：<https://pypi.org/project/boto3/>

* **GitHub**：<https://github.com/boto/boto3>

* **推荐使用**：开发 AWS 相关应用的必备工具，强烈推荐。

```python
import boto3
# 操作 S3 存储桶

s3 = boto3.client('s3')

# 列出存储桶
response = s3.list_buckets()

for bucket in response['Buckets']:
    print(bucket['Name'])
```
