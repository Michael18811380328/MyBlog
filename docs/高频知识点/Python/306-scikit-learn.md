## 306-scikit-learn

"sklearn" 和 "scikit-learn" 是同一个库的不同名称，它们提供了丰富的机器学习算法和工具，可以用于数据预处理、特征提取、分类、回归、聚类、异常检测等任务。

[https://pypi.org/project/scikit-learn/](https://pypi.org/project/scikit-learn/ "https://pypi.org/project/scikit-learn/")

**scikit-learn** is a Python module for machine learning built on top of SciPy and is distributed under the 3-Clause BSD license.

Dependencies

scikit-learn requires:

* Python (>= 3.9)

* NumPy (>= 1.19.5)

* SciPy (>= 1.6.0)

* joblib (>= 1.2.0)

* threadpoolctl (>= 3.1.0)

英文官方网站：<https://scikit-learn.org/stable/user_guide.html>

中文官方网站：<https://scikit-learn.org.cn/>
