## 07-time 对象 sleep 使用

[https://docs.python.org/zh-cn/3.10/library/time.html#time.sleep](https://docs.python.org/zh-cn/3.10/library/time.html#time.sleep "https://docs.python.org/zh-cn/3.10/library/time.html#time.sleep")

Python&#x20;

time sleep() 函数推迟调用线程的运行，可通过参数 secs 指秒，表示进程挂起的时间。

```python
#!/usr/bin/python
import time

time.sleep(5)
```

注意是秒，不是毫秒
