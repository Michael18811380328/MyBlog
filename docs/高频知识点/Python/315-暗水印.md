## 315-暗水印

[https://github.com/guofei9987/blind\_watermark](https://github.com/guofei9987/blind_watermark "https://github.com/guofei9987/blind_watermark")

Blind\&Invisible Watermark ，图片盲水印，提取水印无须原图！

```python
# embed watermark into image:
blind_watermark --embed --pwd 1234 examples/pic/ori_img.jpeg "watermark text" 
examples/output/embedded.png

# extract watermark from image:
blind_watermark --extract --pwd 1234 --wm_shape 111 examples/output/embedded.png
```
