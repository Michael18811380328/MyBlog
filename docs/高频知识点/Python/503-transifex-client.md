## 503-transifex-client

* **分类**：国际化翻译工具

* **功能**：与 Transifex 平台交互，用于上传翻译源文件、下载翻译结果，支持多语言项目。

* **PyPI**：<https://pypi.org/project/transifex-client/>

* **GitHub**：<https://github.com/transifex/cli>

* **推荐使用**：如果项目使用 Transifex 管理翻译，推荐使用；否则无需关注。

```text
# 初始化配置
tx init

# 上传翻译源文件
tx push -s

# 下载翻译结果
tx pull -a
```
