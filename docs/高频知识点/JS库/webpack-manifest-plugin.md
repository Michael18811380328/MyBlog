# webpack-manifest-plugin

生成 manifest.json（这个清单文件记录了原始文件名和打包后文件名之间的映射）文件作用：

* **资源管理**：在生产环境中，Webpack 通常会对文件名进行哈希处理以实现缓存控制。通过 `webpack-manifest-plugin` 生成的清单文件，你可以轻松地找到每个原始文件对应的打包后文件，便于在 HTML 模板或后端代码中引用正确的资源路径。

* **服务端渲染（SSR）​**：在 SSR 应用中，服务器需要知道打包后资源的路径才能正确渲染页面。清单文件为服务器提供了这些信息，确保服务器能够正确引用前端资源。

目前项目不涉及服务端渲染 SSR，所以使用不多
