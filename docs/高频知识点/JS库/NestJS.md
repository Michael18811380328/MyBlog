# NestJS

NestJS 是基于 Node.js 和 TypeScript 构建的**企业级后端框架**，核心定位和优势

* 解决原生 Node.js/Express/Koa 缺乏规范、代码易混乱的问题，提供**模块化、分层化**的架构规范；

* 借鉴 Angular 的设计思想，支持依赖注入、装饰器、面向切面编程（AOP）等高级特性；

* 天生支持 TypeScript（也兼容 JavaScript），类型安全提升开发效率和代码可维护性；

* 生态丰富：无缝集成 Express/Koa（底层 HTTP 引擎）、TypeORM/Prisma（ORM）、JWT（认证）、WebSocket 等；

* 适合开发中大型、高可维护性的后端服务（REST API、微服务、GraphQL 服务等）。

NestJS 遵循「模块化」设计，核心概念：

* **Module**：模块，组织相关的控制器和服务；

* **Controller**：控制器，处理 HTTP 请求，路由分发；

* **Service**：服务，处理业务逻辑（依赖注入）。
