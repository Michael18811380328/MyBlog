# react-moment

react 组件库（实现 moment 的功能）

React component for the moment date library.

星标不多，不是很推荐使用

[https://github.com/headzoo/react-moment](https://github.com/headzoo/react-moment "https://github.com/headzoo/react-moment")

[https://www.npmjs.com/package/react-moment](https://www.npmjs.com/package/react-moment "https://www.npmjs.com/package/react-moment")

```javascript
import React  from 'react';
import Moment from 'react-moment';

export default class MyComponent extends React.Component {
    render() {
        return (
            const dateToFormat = '1976-04-19T12:59-0500';
            <Moment>{dateToFormat}</Moment>
        );
    }
}
```
