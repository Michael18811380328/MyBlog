# Material-UI

复杂的 UI 组件库，google 出品

Material UI is an open-source React component library that implements Google's Material Design.&#x20;

It's comprehensive and can be used in production out of the box.

[https://material-ui.com/](https://material-ui.com/ "https://material-ui.com/")

[https://github.com/mui/material-ui](https://github.com/mui/material-ui "https://github.com/mui/material-ui")

```javascript
import * as React from 'react';
import Button from '@mui/material/Button';

export default function ButtonUsage() {
  return <Button variant="contained">Hello world</Button>;
}
```

这个看起来比 reactstrap 更好看，Vite 等很多网站都使用这个 UI 库
