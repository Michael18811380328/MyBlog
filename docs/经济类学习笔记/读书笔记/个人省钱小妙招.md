# 读书笔记

2026年，开源节流势在必行，个人分享几个省钱小妙招：

1、大型支出一定慎重（上万元的支出），使用 SWOP 分析这个支出是否有必要？（例如一个新款3万元的公路自行车，或者一个30万的宝马3系小汽车，或者200万买一套房子）把这个目标写在纸上，1个月或者1年后看是否切实需要这个支出。如果不需要，删除，如果需要，努力去实现。

2、避免消费数字化：现在社会中，很多都是电子支付，例如买一个新款的苹果手机是6000元，如果直接微信支付宝，或者信用卡支付，只是一个数字，可能 60000 就比6000 多按1个0。实际上支出建议使用纸币，感受一下这6000元是多少钱，然后这样也不会超预算。例如不会把原定买6000的手机，直接支付宝花呗买了7000的高配手机。

3、不要被别人的眼光观点干扰自己的决策。例如我只穿了1个月的鞋子，我妈说过年一定要买新的。但是我没有必要买。例如我的自行车就是2000元，朋友说他们都是20000的车，建议我也买。我觉得2000和20000的车子对我影响不大，后续维护成本高，所以我不买。

4、非必要的小额支出，暂缓实现：很多时候，我发现现在手机购物软件（淘宝，拼多多）等，随便一点就下单输密码，我个人习惯是可以逛淘宝，然后把所有喜欢的东西放在购物车或者收藏中（例如选择了100件）。逛完后，删除这100件中同类商品（例如2个手串，删除1个，保留1个），这样就剩余50件商品。然后就选择其中最重要的5件商品购买，每个月买一件商品（这个月的收入到账后，买一件商品），这样就可以大大减少不必要支出。
