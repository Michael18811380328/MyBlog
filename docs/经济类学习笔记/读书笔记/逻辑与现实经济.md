#### 房屋养老金

问题：2024年6月11日，22个房屋养老金试点之一的天津市滨海新区住建委发布『关于对《天津市滨海新区房屋养老金管理办法（征求意见稿）》公开征求意见的公告』。办法基本明确了房屋养老金公共账户只承担房屋检测和办事人员薪酬，个人账户承担房屋维修费用，而且用完需要补交。另外，在交易、继承、赠予等过户环节时会核查是否有漏交少交的情况，如有会限制过户。其他试点城市是否会保持基本一致的实施方案，如按该版办法实施，对未来房地产市场有何影响？

[https://www.zhihu.com/question/666298872/answer/3620471502](https://www.zhihu.com/question/666298872/answer/3620471502 "https://www.zhihu.com/question/666298872/answer/3620471502")

首先，千万不要觉得房屋养老金和房地产税是替代关系，未来更可能是互补关系，前者是专款专用的公共资金池基金，后者是无偿性和强制性的地方税，不是收了这个就不收那个，而很可能是既要收房地产税，也要收房地产养老基金。

原因也很简单，公共维修基金和地方财税在未来（已经）面临巨大的缺口，尤其是地方财政，已经开始“砸锅卖铁”的化债了，或者靠特色地方平台融资兜底，结合房企拍地土地，继续维持每年5万亿以上的土地财税，相比来说还是比房地产税规模更大，短期紧迫性不强，阻力也很大，2022年官方公开发生短期内不适合全面推广房地产税，但不意味着存量房屋时代地方财政缺口继续暴漏下就不收，尤其是房地产高涨周期的房子，未来收房屋养老金和房地产税的可能性非常大。

其次，试点阶段各地的政策可能会有较大的差异，用于测试数据和看市场的反馈，就好比最早一批试行房地产税的上海和重庆就有较为明显的差异，天津滨海新区的政策暂时也只能作为参考，模式也相对明确，公共资金用于定期体检和相关部门的人员开支，查出问题之后的整改维修则要动用大修基金，用完需要补交可能并不准确，按照过去的相关规定，应该是低于资金池要求的30%则要继续补觉，房龄和房屋公共维修基金余额将成为影响房地产定价的最重要的因素之一。举一个简单的例子，假设未来老房子资金缺口是10万，个人公共维修基金余额1万，那么现在的市场定价就要把这些潜在的资金缺口计入到定价里面。

房地产维修费用缺口是随着房龄的增加而迅速增加的，现在最紧迫的是老旧房子，一般认为是房龄超过30年的老旧小区，这类房子的特点是当时市场化程度低，分房还是非常主流的方式，房地产维修基金政策也并不完善，随着时间的推移，这类房子逐渐进入老龄化阶段，维修改造的压力最大，但也最缺钱。那么钱从哪里来？靠纳税人? 靠后来者？都不显示，所以走的应该是日本模式，有点像日本的修缮积立金，而房地产养老金的公共资金池，更像是增加一个管理部门，专门负责对房屋的安全进行评估和监管，确定是否需要维修，至于未来是否会下场选定特定的维系机构和公共资金池的使用，可能还要存疑，现在看来更像是监管和评估部门，资金池的来源可能是财政补贴，也可能是大修基金的收益，比如按照2%的无风险收益评估，一年公共维修基金存量大概可以创造200亿左右的收入，这部分可能会划转到公共资金池，结合一般公共预算收入和土地出让金的划转，确实明面上不需要居民直接承担这部分的开支。

设卡方式是过户，需要查看房屋公共维修基金的余额，否则无法完成过户，这对于记成、赠予影响非常大，这也能理解为什么很多日本偏远房子是免费赠送的，遗产税要交钱，假设房屋状况较差，维修基金缺口太大，且出租本身收益有限（空心化区域），房子白菜价都不夸张，修缮积立金、房产税遗产税等各类费用缴纳之后，就是纯纯的负资产，这也是老龄化人口负增长结合房屋老龄化之后的结果。以后我们人口负增长开启以后结合各类费用的增加，比如维修基金和房产税，房子价格和成本会是什么样还真不好说。

天津滨海区的房地产养老金，明确了公共资金池的作用，就是房屋检测和办事人员薪酬，暂时没说钱的来源，而现在真正影响比较大的是高房龄且缺乏公共维修基金的房子，因为新房子都交过了，老房子更多的是补交，且随着土地财税的减弱，拆字越来越难，剩下的老旧小区也只能改了，以前拆迁换了房子还有的赚，现在后来者没钱了，也拆不动了，老旧房子出问题的概率高，一出问题就是公共安全问题，火灾塌房随着房屋老龄化也会越来越多，钱要么业主出，要么财政出，没有别的办法。

至于未来，新房子也不要幸灾乐祸，只是现在房龄低还不到大规模应用和资金缺口的时候，2008年以后我国进入了高速的城镇建设中，大量的高层住房出现，结合特色预售制和房地产企业的高周转要求，期间房屋质量怕是要打一个打问号，更何况这几年大量的保交付项目在资金紧缺下的质量问题，几年出问题的都一大堆，更何况十几二十年之后密集出现资金缺口，那存量的1万亿根本就不够，未来低于30%就要补交，如果资金使用效率高一些，也无可厚非，自己的钱修自己的房子，最重要的给我们两个警示：

1）房子是会老化的，房价也不是永远涨，未来的定价一定是与房屋的房龄、保养程度、公共维修基金余额等高度相关，买房子一定要兼顾更多的因素和潜在成本。

2）房屋现在得成本主要是一次性的土地税，未来极大概率还有无偿和强制性的房地产税（城市公共福利税），房屋的维修费用，成本除了物业费以外还要额外增加其它潜在费用，房地产税与房子估值有关，房地产维修基金则与房龄有极高的关系，前者反缴纳的钱变化可能更稳定一些，后者则可以确定的是越交越多，未来出现持有成本大于收益的情况会越来越多，尤其是人口结构失衡的地区，年轻人口大规模流失之后连需求都没有，继承就要交税交房屋养老基金，而定价则可能鹤岗化，这就不是白菜价的问题了，而是各类费用下的负资产和负担。

高位变现的窗口已经远去，而未来的潜在成本还在不断增加，房地产游戏性质早就变了，但作为居民最大的财富占比，广义税明面税源的本质可能还不会消散，未来谁房子多谁多交税不也顺理成章么。
