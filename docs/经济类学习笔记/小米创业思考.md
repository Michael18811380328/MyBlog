# 读书笔记

小米公司创业过程中的经历和思考

雷军系统梳理30年创业心法和经营哲学，深度复盘“小米模式”，认为取得持续成功的核心在于只干了一件事：坚持“互联网制造”路线，推动效率革命，实现用户利益和经济效率的最大化。

雷军在书中首度全面公开包括三大铁律、七字诀、高效率模型、爆品模式、生态链要素等，涉及管理、投资、工作等多维度经验，为创业者和管理者提供借鉴和指导，也可以为普通人提供持续精进的头部思维。

​

小米创业十年过程的会议和思考，2022年写

> 感动人心，价格厚道——追求极致的性价比，硬件利润率不超过 5%（低价策略依靠量抢占市场，类似的还有目前的胖东来，赵一鸣零食，都是依靠供应链确保低价产品，让用户性价比最高）

> 核心方法
>
> 把互联网的开发模式用在制造业中，提高效率
>
> 例如多听用户的反馈，对用户说的有必要的改动多改动。

专注：优先专注核心技术点（电话，通讯录，短信），如果考虑的太多方面，产品质量很难把控。

极致：把一个产品做到最好，例如手机对标苹果手机供应链，汽车对标保时捷和兰博基尼。

口碑：让用户成为口碑和宣传

快：快速迭代，每天发布测试版本，每周发布内测版本，针对核心用户进行有风险测试。每月发布中等稳定版本，将新功能介绍给外部用户。
