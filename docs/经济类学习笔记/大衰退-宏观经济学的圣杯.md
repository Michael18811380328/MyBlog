# 读书笔记
  
王克丹推荐

介绍2008年国际金融危机，以及避免策略的书籍

主要途径，避免资产负债表缩水（避免价格下跌）这个主要是国家在做，稳定房价，避免所谓的中产阶级资产缩水。

序言，这本书作者是辜朝明（辜振浦的儿子，已经加入日本，经济学家），分析了日本经济的衰退，和传统美国经济大萧条的原因不同。日本经济衰退是资产负债表衰退，表现就是企业缩小生产规模，减少银行信贷业务，造成资产衰退。
