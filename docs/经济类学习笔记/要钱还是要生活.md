# 读书笔记

最近速读了这本《要钱还是要生活》，豆瓣评分 7.5分，我感觉还不错，分享一下。

这本书作者是维姬罗宾 / 乔多明格斯，主要介绍了FIRE （Financial Independence，Retiring Early）的精髓，就是被动收入覆盖日常开支，就实现了财富自由，早日退休，以及如何实现量入为出，增加输入，减少开支，实现 FIRE 的基本条件。

适合人群：这本书适合认同 FIRE 理念，消费大于收入，没有存款，但是希望有存款的人，对普通小白也是很好的入门书籍。如果有一定的财务和会计基础，很容易理解这本书的内容。

主要内容和我的思考：

1、明确个人资产负债表：个人总收入，个人总资产（包括灵活资产，固定资产）。总收入 - 总资产 = 总开支。统计过程尽可能详细，不确定的部分，可以使用估算进行预测。统计的目的就是确定个人的财务情况。

2、分析个人的月度开支，明确每一个收入和支出。必须支出是否能节省（例如租房和吃饭，能否换一个性价比更高的房子）？非必须支出是否能去掉（新款的手机，是否一定买）？

3、列出梦想，然后为梦想分配足够的资源（时间+金钱等），需要查看自己的开支和梦想的相关程度。如果是强相关的开支，就去优先满足。如果是弱相关的开支，就推迟满足。

4、合理投资，使用合理的投资策略，让被动收入覆盖日常开支，就可以早日实现退休。

> 按照国内三线城市，租房子住，每月支出2750元，每年支出33000元。按照投资收益率 2% 无风险收益的计算，那么拥有165万本金存款+国债，就可以实现被动收入覆盖支出，早日退休。（方案不动本金，不考虑通货膨胀，战争动荡等情况）

5、上学工作加班不是人生目的，需要问清自己的内心，人生的目的和意义是什么？自己的梦想是什么，是有豪宅和豪车，还是有学术成就，还是找白月光结婚，还是周游世界，还是有足够的社会地位，还是要10个子孙后代？确定目标后，就朝着这个目标努力。

局限：书中提到的还是美国的情况（例如国税局，404 计划，美国投资方案），中国的情况需要按需调整。
