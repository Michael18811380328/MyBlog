# 读书笔记

2023年的豆瓣读书榜单（经济类榜单）

本书是1987‑2022年芒格股东会现场讲话实录，是实战版的芒格思想，兼顾投资、商业、人生处世。

#### 一、思维认知

1. 多元思维模型（格栅思维） 不要只用单一学科看待问题，避免“手里拿着锤子，看什么都是钉子”。吸收数学、物理、生物、心理学、经济学等基础原理，多模型交叉验证，减少认知盲区。(避免个人是程序员，什么都希望用编程思路解决)
2. 逆向思考：反过来想，总是反过来想。少研究如何成功，重点研究如何会失败。把失败的条件全部避开，就更容易得到好结果。例如远离杠杆、远离看不懂的东西、远离糟糕的管理层。
3. 能力圈原则：清楚自己懂什么、不懂什么。只在自己理解的领域做决策；不懂就不碰，可以慢慢拓展边界，但不要强行出圈。承认自己无知，是智慧的开端。
4. 保持客观理性，警惕心理误判：人天生有大量心理偏见：从众、嫉妒、自欺、厌恶损失、受激励操控等。要时刻反省，不要欺骗自己，自己是最容易被自己欺骗的人。
5. 终身阅读、持续学习：不靠小聪明取胜，靠持续的知识积累；每天争取让自己比昨天聪明一点点。

#### 二、投资商业理念

1. 公道价格，买伟大公司，放弃烟蒂股：宁可以合理价格买入优秀企业，不要很便宜买入平庸企业。优秀企业自带复利，时间是好公司的朋友，是烂公司的敌人。
2. 重视护城河（经济商誉） 寻找拥有品牌、规模、成本优势、网络效应的企业；优先选护城河能够持续加宽的公司。
3. 集中投资、耐心等待机会 好机会并不多，机会来了要下重注；平时大部分时间只是等待，反对频繁交易、过度分散。不要用杠杆，一次重大亏损，复利就会被毁掉。
4. 安全边际 做决策预留容错空间，不要把未来设想得全部理想化，给自己留缓冲。
5. 管理层与企业文化非常重要 再好的业务，糟糕的管理层也会把企业搞垮。看企业不能只看财报数字，要看人的品行、公司文化。
6. 拒绝追逐热点、跟风市场 大众狂热的时候保持冷静，市场恐慌的时候保持客观，不被华尔街的主流风气裹挟。

#### 三、人生处世

1. 品格是最高回报的策略：诚实、可靠、克制，不耍小聪明，长期收益远高于投机取巧。
2. 降低欲望，延迟满足：不攀比，控制欲望，拒绝短期快感。
3. 避免陷入嫉妒、怨恨、自怜，这些负面情绪会毁掉一个人。
4. 简单化生活：把复杂问题简化，抓住最重要的几件事，不要追求事事完美。

#### 四、重要提醒

这本书不是短线炒股教程，核心是提升思考质量。

投资只是理性思考的副产品，先把思维、性格、判断力建好，财富才会随之而来。
