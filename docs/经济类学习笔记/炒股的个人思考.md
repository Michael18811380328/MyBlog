# 读书笔记

深刻认识到，自己是普通投资者（散户），智商不如 AI deepseek，操作精度不如量化交易，投资技术和时间不如机构，自己的投资目的是稳定赚钱，跑赢通胀（不是一夜暴富）。

决策：合理分配投资产品的仓位和比例，每月进行复盘和微调，每年进行年度总结和整体调整。保证每年正收益的前提下，尽量多赚，跑赢通胀，实现理财收入覆盖日常支出。

投资产品分配：

1、银行：定期存款+国债+理财（国债+美债理财），比例 30%

2、基金：优质债券基金。比例 50%

3、股票：主要是可转债打新，没有很高把握**不投资个股**（确定投资的时间，依据，目的，预期收益）

4、黄金：黄金和世界局势密切相关，是避险资产，可以根据个人判断，适当投资

5、指数：只考虑优质指数，例如纳斯达克+标普500，尽量不考虑行业指数

投资资金比例：**灵活使用 5%​，​中低风险 85%​，​高风险10%。​**
