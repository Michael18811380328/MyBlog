# 读书笔记

深刻认识到，自己是普通投资者，就是一个散户，智商不如 deepseek，操作精度不如量化交易，投资技术，操作时间不如机构，自己的投资目的就是稳重赚钱，跑赢通胀。

决策：合理控制总投资产品的仓位和比例，每周进行微调，每月进行复盘，每年进行年度总结。在控制总体风险的基础上，保证每年正收益的情况下，多赚一些。

银行理财：定期存款+国债+债券理财+美债理财，合理分配，按年度统计最大回撤0，尽量追求最大利润

基金：投资优质基金（基金经理）

股票：**不建议投资个股**，除非自己有95%的把握这次投资有收益（具体投资的位置，投资的依据，投资的目的）

黄金：黄金和世界局势密切相关，是避险资产，可以根据个人判断，适当投资

指数：考虑投资优质指数，例如纳斯达克：标普500指数，不考虑国内宽指数（根据历史指数发展判断），指数风险较高。

​

**建议灵活使用仓位 5%​**

**建议中低风险仓位 85%​**

**建议高风险投资品（黄金+指数）不超过10%。​**
